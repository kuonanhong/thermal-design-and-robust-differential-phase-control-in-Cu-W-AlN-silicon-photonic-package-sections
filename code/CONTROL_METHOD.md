# Pairwise optical control: model and exact scope

`control_analysis.py` uses `results/control_inputs.npz`, produced by the package-scale thermomechanical solver and optical sensitivity projection. The response matrix H has units rad/mW. Each column is the optical phase generated by one heater, including its thermal and elastic influence on every optical sampling location. It is not an assumed Toeplitz cross-talk matrix.

## Observable and objective

The nine values represent equal-length, longitudinally invariant optical paths at nine lateral positions. Their relative phases are relevant to a balanced interferometer that compares any two such paths. This is a screening architecture; the code does not claim that a fabricated nine-channel interferometer was simulated or measured.

For pair i,k, let b_ik = phi_i - phi_k, D_ik = H_i - H_k, and S_ik = |H_i| + |H_k|. The nominal pair phase after applying heater powers p is b_ik + D_ik p. Minimizing its maximum absolute value over all 36 pairs removes a spatially uniform phase shift. This is equivalent to minimizing twice the radius about an optimally chosen common phase, and this equivalence is verified independently by a second LP construction. There is no arbitrary fixed absolute phase target.

The optimization stays on one unwrapped phase-locking branch. It does not search integer 2 pi phase wraps, and conclusions about infeasibility apply to this branch and the stated heater bounds.

## Pre-round robust LP

Each sensed background phase differs from its true value by at most epsilon. The baseline matrix uncertainty is an independent entrywise interval, |Delta H_ij| <= eta |H_ij|. Uniform endpoint-inclusive DAC levels have spacing q_j = Pmax_j/(2^B - 1). Nearest rounding obeys |p_q,j - p_j| <= q_j/2 and always remains within [0,Pmax_j].

For both signs s = +/-1 and every pair, the LP imposes

s(b_ik + D_ik p) + eta S_ik p + 2 epsilon
+ sum_j |D_ik,j| q_j/2 + eta sum_j S_ik,j q_j/2 <= z.

The last term accounts for the product of response uncertainty and command rounding; omitting it would not provide the stated guarantee. The total continuous power budget is reduced by sum_j q_j/2 so the rounded commands also meet the physical total budget. A per-heater reserve is unnecessary because both bounds are DAC endpoints.

The first LP minimizes z; a second LP minimizes total power while preserving z to within 1e-8 rad. A separate set of LPs minimizes total power subject to a specified phase certificate. Infeasibility in the robust LP means that this sufficient pre-round certificate cannot be met. It does not prove that every possible discrete command is physically infeasible.

This is a standard robust linear-programming construction applied to a coupled physical model. No claim is made that linear programming, the triangle inequality, or minimax phase control is itself new.

## Exact post-round interval certificate

After p_q is known, its exact worst-case pair range over the baseline uncertainty set is

C_post = max_(i,k) { |b_ik + D_ik p_q| + 2 epsilon + eta S_ik p_q }.

No rounding margin remains because the quantized command is now fixed. This exact certificate is no larger than the pre-round certificate. For each pair, independent signs of sensor and matrix errors attain the corresponding bound; maximizing over the pairs commutes with maximizing over the uncertainty set. The code checks explicit adversarial corners as well as paired random perturbations. The discrete command produced by rounding is not claimed to be a globally optimal mixed-integer solution.

## Physically distinct uncertainty structure

`control_sensitivity.csv` also considers column-correlated heater gain errors, H_true = H diag(1+delta), |delta_j| <= eta. Replace S_ik by |D_ik| in every matrix-uncertainty term. This preserves the common-mode part of each heater response. The two uncertainty sets answer different calibration questions; neither is asserted to be experimentally established. The sensitivity study exposes how the uncertainty model changes the certified power/phase tradeoff.

## Interferometric penalty

For a lossless, balanced MZI observed at its nominal constructive port, normalized transmitted power is cos^2(delta/2). A phase bound C in [0,pi) therefore gives a worst-case excess penalty -10 log10[cos^2(C/2)]. If C >= pi, the interval includes a dark port and no finite worst-case penalty is reported. This quantity excludes propagation, coupling, scattering and absorption loss; it must not be described as measured or total package insertion loss.

## Executed checks

The verification suite checks analytic two-lane heater power and budget-limited residual, the null differential effect of identical heater-response rows, invariance to a 900 rad common phase shift, equivalence to an independent floating-target LP, and 1,800 adversarial/random uncertainty cases. The additional uncertainty-structure suite checks all pairwise adversarial corners for its feasible solutions. Run `python control_analysis.py --verify-only` for the analytic checks, or run the default command to rebuild all optimization tables and figures.

Main sweeps: 6/8/10 bits; per-heater maxima 10/20 mW; total physical budgets 25/50/100 mW; entrywise response bounds 0/2/5%; per-path sensing bound 0.002 rad. Paired random perturbations are sampled 128 times per minimax case. The sample counts are model checks, not fabrication yield. All model/command arrays and random perturbation shapes are retained to allow independent reconstruction.
